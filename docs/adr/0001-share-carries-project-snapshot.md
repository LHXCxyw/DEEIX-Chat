# 1. 分享对话携带项目工作区快照

Date: 2026-10-14

## Status

Accepted

## Context

`/share?conversation_id=<shareID>` 当前只渲染对话消息与其**消息附件**（含生成的图片/视频），
完全不含项目工作区文件。用户要求分享后能看到产出文件并预览渲染效果。

分享机制是"混合语义"：标题、平台模型、消息 public_id 集合在创建分享时**冻结为快照**；
消息正文、附件、模型名、轨迹则按当前数据库**实时读取**。项目工作区文件既未被快照，也未对匿名访问暴露。

若让分享页"实时读取所有者当前工作区"，所有者后续的编辑/删除会改变甚至破坏已分享链接；
且与"分享是一份可复现记录"的语义相悖。

## Decision

分享对话时**冻结项目工作区文件快照**：记录文件清单（相对路径 + 不可变原件引用），
并新增以 `share_id` 鉴权的公开只读端点，仅能读取该快照内的文件。

被冻结的是"清单 + 版本引用"，不是文件字节；原件本身不可变（见术语「原件」），
因此快照引用天然稳定。

## Consequences

- 已分享链接的内容稳定可复现，不受所有者后续改动影响。
- 新增分享快照存储与公开只读端点；分享模型需扩展（当前 `ConversationShare` 无 project 字段）。
- 分享页新增"文件"区：只读文件树 + 预览（HTML/SVG 沙箱可运行、图片/视频直连、文本只读）。
- 分享创建后新产生的文件不会出现在该分享中（符合快照语义）。
