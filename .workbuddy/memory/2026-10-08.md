## 删除文件 500 但文件已删（簿记步骤失败）
- 新版部署后症状变化：删除返回 500 "delete project file failed" 但刷新后文件已删 → repo 删除成功，recordProjectFileChange 或 UpdateProjectWorkspaceUsage 其中一步报非 ErrNotFound 错误。
- 修复：两步簿记改为失败仅记 warn 日志（project_file_delete_change_log_failed / project_file_delete_usage_update_failed），不再让请求失败；删除主体成功即返回成功。
- 注意：变更日志缺失会影响 rewind 精确恢复该删除操作（短期接受），根因待日志确诊。

## 工具策略调整：手动选工具则启用，内置文件工具下线
- resolveSelectedToolRuntime 移除两处 addProjectToolDefinitions 自动注入；service_message_send.go 撤销 withoutAllDefinitions 特判。
- 最终规则：工具=用户在 composer 显式选择的 MCP 工具（项目/非项目会话一致）；未选择则纯一问一答；内置 project_* 文件工具不再提供给模型（工具执行代码保留未删）。
- 影响：AI 无法再自动读写项目工作区文件（除非未来把 project_* 加入可选列表）。
- 全量构建仅 sqlite-vec cgo 环境预存限制，改动包编译通过。
