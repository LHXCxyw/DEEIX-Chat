## git「幻影 modified」的成因与修复
- 现象：git status 报 954 个文件已修改，但 git diff 与 git diff --quiet 均显示无内容差异。
- 成因：本机 core.autocrlf=true（来自系统级 gitconfig）叠加 .gitattributes 的 * text=auto，工作区文件为 LF 而 git 期望 CRLF，status 因此产生「幻影 modified」。
- 修复：git add --renormalize . 即可归零；结果只暂存了 55 个真实变更（而非 954）。另将改动文件统一为 CRLF，消除 9 处混合行尾符。
- 教训：PowerShell 中 @(git ...) 会把 git 的 stderr 警告混进结果数组，计数被放大（970 = 55 真实 + 899 警告 + 16 未跟踪）；统计必须用严格 porcelain 正则，或改用重定向。
